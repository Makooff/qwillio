Aucune version finale entièrement française, anglaise ou néerlandaise n'a été identifiée parmi les contenus classés. Les dossiers sont prêts pour les recevoir. Les scripts sont des brouillons à vérifier avant tournage, notamment les tarifs et les affirmations commerciales.

## Ranger un nouveau contenu

1. Mets une vidéo dans `videos/`, une image dans `photos/`.
2. Choisis `francais/`, `anglais/` ou `neerlandais/` selon le texte ou la voix. Si plusieurs langues figurent dans une vidéo, utilise `multilingue/`. Une photo sans texte va dans `photos/sans-texte/`.
3. Donne un nom explicite, par exemple `demo-plombier-verticale-30s.mp4` ou `presentation-receptionniste-carre.png`.
4. Pour une publication complète, garde sa légende à côté du média, avec le même nom et l'extension `.md`.
